# LocalVault-Fill 浏览器扩展（v1.9.3 自动登录填充版）

自用解压加载扩展（不上架应用商店）。与 LocalVault 本机填充服务配对后，在登录页密码框旁显示 🔑 按钮，点击即可选择匹配账号一键填充。

## 安装（解压加载）

1. 打开 Microsoft Edge（或 Chrome）的 **扩展管理** 页面：地址栏输入 `edge://extensions/`（Chrome 为 `chrome://extensions/`）。
2. 打开右上角「开发人员模式」开关。
3. 点击「加载解压缩的扩展」，选择本目录（`extension` 文件夹，含 `manifest.json` 的那一层）。
4. 扩展栏出现 🔐 LocalVault-Fill 图标即加载成功。

## 首次使用

1. 启动 LocalVault，解锁 Vault。
2. 菜单栏「🌐 浏览器填充」（或侧边栏「系统 → 🌐 浏览器填充」），打开「启用填充服务」**总开关**（只需打开一次，之后保持记忆）。
3. 在弹窗中点击「生成 6 位配对码」。
4. 点击浏览器扩展栏的 LocalVault-Fill 图标，在弹窗中输入配对码，点击「配对连接」（**配对一次即可**，之后免重复配对）。
5. 访问目标登录页面，点击密码框旁的 🔑 按钮，在列表中选择对应账号即可自动填充。

## 工作方式与安全边界

- 填充服务仅监听 `127.0.0.1:38527`，外部网络无法访问。
- 所有接口使用 Bearer 令牌鉴权；令牌仅存在于扩展 service worker 的会话存储中，content script 不持有令牌。
- 配对码为 6 位一次性，5 分钟有效；配对关系持久化保存，一次配对后 Vault 解锁即可自动恢复连接。
- 域名匹配支持子域双向匹配（`login.example.com` ↔ `example.com`）。
- 密码只在点击填充的瞬间经本机回环接口下发，扩展不保存、不上传任何密码。
- Vault 锁定自动停止服务、销毁令牌并断开配对；再次解锁自动恢复，无需重新配对。

## 常见问题

**点击 🔑 提示「本机填充服务未运行」**：确认 Vault 已解锁（解锁状态下服务会自动运行）；若仍未运行，检查「🌐 浏览器填充」总开关是否已打开。

**提示「未配对」**：若从未配对过，需在 LocalVault 中重新生成配对码（旧码一次性）；已配对过的设备解锁后会自动恢复连接。

**列表为空**：确认保存的条目「网址」字段与当前登录页域名一致（支持子域双向匹配）。

## 手动安装到本机其他浏览器

Chrome、Edge 均支持以上「加载解压缩的扩展」方式。Firefox 需要签名或开发者模式，本期未做适配。
