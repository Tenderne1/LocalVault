# LocalVault V1.5 UX / Security Changes

- 查看密码默认进入只读模式；只有点击“编辑密码”才允许修改。
- 编辑过程中切换条目、切换分类、点击空白、锁定时会提示保存/放弃。
- 密码生成器只在编辑模式出现，降低误操作风险。
- 密码条目增加唯一序号、账号类型、密码名称、用户名/邮箱/手机号、平台昵称、网址/IP/APP、过期设置、标签等字段。
- 分类支持默认图标与自定义 emoji 图标。
- 过期前 7 天列表标红并显示提醒。
- 删除支持单条与批量删除，并二次确认。
- 修改历史仅保存“发生变化的字段名 + 时间”，不保存旧值/新值；每个账号最多保留最近 3 次。
- 加密导出使用 `.lvx`，禁止 CSV/Excel/明文导出；导入只接受 LocalVault 加密格式，并在解锁 Vault 后解密。
- 导入重复账号按“类型 + 用户名”判断，冲突可逐条选择替换或跳过。
- 类型、标签可在编辑界面扩展，非秘密元数据保存在本地 UI 设置中。

## 数据兼容
旧版 Entry JSON 缺失的新字段均有默认值，因此旧 Vault 可以继续读取；下一次保存时会写入新字段和 V2 格式版本。

## 设计取舍
“不可恢复删除”针对应用正常操作：删除后不提供应用内回收站。为了 Windows 上的原子替换，底层升级仍需关注旧版本留下的备份文件策略；正式发布前建议增加安全擦除/版本化备份策略审计。
